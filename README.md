# 🎙️ Alexa+ MCP Agentic Productivity Assistant

> **Submission for the Build, Ship, Shape: Amazon Developer Hackathon**

An agentic productivity assistant integrated with a custom **Model Context Protocol (MCP)** server in Python, powered by **Google Gemini 1.5 Flash** and a **Streamlit** user interface.

---

## 🌟 Key Features
- **Custom MCP Server:** Implements 3 core tools (`organize_tasks`, `summarize_workspace_context`, `export_action_plan`).
- **Live MCP Inspector:** Real-time sidebar visualization showing tool call events and JSON payloads.
- **Spec-First Architecture:** Complete progressive documentation (`scope.md`, `prd.md`, `spec.md`).
